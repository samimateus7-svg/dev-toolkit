Debounce Function for UI Optimization

Limits the rate at which a function can fire. Perfect for handling window resizing, scrolling, or real-time search inputs elegantly without destroying performance.

const debounce = (fn, delay) => {
    let timeoutId;
    return (...args) => {
        if (timeoutId) clearTimeout(timeoutId);
        timeoutId = setTimeout(() => fn(...args), delay);
    };
};

Throttle Function for Rate Limiting

Ensures a function is called at most once in a specified time interval. Ideal for continuous event streams like drag-and-drop, canvas rendering, or window scroll listening.

const throttle = (fn, limit) => {
    let inThrottle;
    return (...args) => {
        if (!inThrottle) {
            fn(...args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
};

Deep Clone Objects & Arrays

Creates a completely detached clone of complex objects or nested arrays. It leverages native modern platform APIs while maintaining zero external dependencies.

const deepClone = (obj) => {
    if (obj === null || typeof obj !== "object") return obj;
    
    // Modern modern browsers fallback using native structuredClone
    if (typeof structuredClone === "function") {
        return structuredClone(obj);
    }
    
    return JSON.parse(JSON.stringify(obj));
};

URL Query Parameters Parser

Converts the browser's current `window.location.search` query parameters directly into a clean, key-value JavaScript Object for state management.

const getQueryParams = () => {
    const params = new URLSearchParams(window.location.search);
    const entries = params.entries();
    return Object.fromEntries(entries);
};

Relative Time Formatter (Time Ago)

Calculates the relative distance between a target date and the present, parsing it into a human-readable text string like "3 hours ago" or "just now".

const timeAgo = (date) => {
    const now = new Date();
    const seconds = Math.floor((now - new Date(date)) / 1000);
    
    const intervals = {
        year: 31536000, month: 2592000, day: 864000,
        hour: 3600, minute: 60
    };

    for (const [unit, value] of Object.entries(intervals)) {
        const count = Math.floor(seconds / value);
        if (count >= 1) {
            return `${count} ${unit}${count > 1 ? 's' : ''} ago`;
        }
    }
    return 'just now';
};
